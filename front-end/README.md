# PuntualiX — front-end

Aplicación React + TypeScript + Supabase. La documentación completa, la arquitectura y el registro de cambios
están en el [README principal](../README.md).

```bash
npm install
cp .env.example .env.local   # credenciales de Supabase
npm run dev
```

- Base de datos y conexión: [supabase/README.md](supabase/README.md)
- Diccionario de datos: [supabase/DICCIONARIO_DATOS.md](supabase/DICCIONARIO_DATOS.md)
