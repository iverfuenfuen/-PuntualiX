Registrar Nuevo Instructor

HU02.1

Vincula un nuevo docente para habilitar el seguimiento de asistencias y asignación a fichas SENA (HU02.1).

Se utilizará para notificaciones de turno y credenciales de acceso institucional.

Antes de registrar

  • El documento de identidad y correo electrónico deben ser únicos en el sistema PuntualiX.
  • El instructor recibirá sus credenciales temporales de acceso vía correo institucional una vez completada la vinculación.
  • Después de registrar, quedará inmediatamente disponible para ser asignado a una o varias fichas formativas.
  • Los permisos asignados delimitan las fichas y competencias sobre las cuales podrá registrar asistencias y gestionar novedades.
